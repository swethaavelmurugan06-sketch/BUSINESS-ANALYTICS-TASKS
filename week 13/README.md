# 📊 E-Commerce Sales Analysis Dashboard Using Tableau

## 📌 Project Overview

This project explores e-commerce sales data using Tableau Public to identify sales trends, product performance, regional differences, and category-wise performance. The interactive dashboard helps users understand business performance through visual analytics.

## 🎯 Objectives

* Analyze sales trends over time.
* Compare sales across different regions.
* Explore product-wise sales performance.
* Understand category-wise sales distribution.
* Identify meaningful business insights.
* Support data-driven business decisions.

## 🛠️ Tools & Technologies

* Tableau Public
* Microsoft Excel
* Data Visualization
* Exploratory Data Analysis (EDA)

## 📈 Dashboard Features

* Interactive sales dashboard
* Monthly sales trend analysis
* Product sales contribution using a Packed Bubble Chart
* Regional sales comparison
* Category-wise sales analysis
* Interactive filters for exploring the data
